# 益生菌干预响应预测模块

## 目标

预测不同受试者对益生菌、益生元、合生元或饮食干预的响应概率。

## 输入

- 基线宿主变量
- 基线菌群变量
- 干预变量
- 队列变量
- responder label

## 输出

- responder prediction model
- intervention response probability table
- responder microbiome signature
- non-responder microbiome signature
- leave-one-study-out validation report
