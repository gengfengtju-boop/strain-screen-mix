# 微生物组特征构建模块

## 目标

由分类丰度、功能通路和元数据构建可建模特征矩阵。

## 输入

- `taxonomic_profile`
- `functional_profile`
- `sample_metadata_clean.csv`
- `config/feature_config.yaml`

## 输出

- genus abundance matrix
- species abundance matrix
- pathway abundance matrix
- diversity feature matrix
- mechanism-derived feature matrix
