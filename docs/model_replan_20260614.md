# 模型重新规划（基于 2026-06-14 严格化更新）

## 一、更新做了什么（方法学严格化）

2026-06-14 的更新把效应量综合从"够用"提升到"严谨"：

| 维度 | 旧（06-13）| 新（06-14）|
|---|---|---|
| 方差政策 | 含 p 值反算 SE | **仅直接方差**（reported CI 或臂级 SD+n）；p 值反算降级为敏感性 |
| 合并方法 | DerSimonian-Laird | **Paule-Mandel τ² + 修正 HKSJ 区间**（小样本正确方法）|
| 去重 | 部分 | 11 组发表别名去重 |
| 共干预 | 未处理 | 18 行标记 + 排除敏感性 |
| 稳健性 | 无 | 缺失方差三角验证（中位/上四分位填补 + 10000 bootstrap）|
| 证据层 | 无 | 严过滤下信号是否存活的敏感性分析 |
| 质量审计 | 无 | 主分析资格（137 行 → 55 合格 / 19 试验）|

## 二、更新发现了什么（诚实结果）

**核心数字**：严格直接方差下，**仅 weight|kg 可被 meta 分析**（k=4 直接方差）：
- pooled **−1.62 kg [−3.24, −0.006]**，CI 勉强排除 0
- 但 **I²=76.4%**（高异质性）、**预测区间 [−6.0, +2.8] 跨 0**、p 值反算敏感性（k=5）**[−3.18, +0.57] 含 0**
- → 标记 **`replication_ready: False`**

**其余 stratum 全部 `insufficient_direct_variance_studies`**（直接方差 <3 研究）：
- **body_fat|kg：直接方差仅 k=1** → 不可 meta；审计裁定为"复制假设"——效应**双向**（4 负 2 正）、菌株/剂量元数据稀疏。
- BMI、lipid、waist、glucose 同样直接方差不足。

**汇总**：
- `strata_replication_ready`: **0**
- `strata_beating_null_baseline`: **0**
- `combination_ranking_enabled`: **false**

## 三、对既有结论的修正（重要）

> **v1 交付报告第 5 节的"body_fat 合并 −0.44 kg [−0.74,−0.13]，CI 排除 0，一致减脂"不再成立。**

那个结果是**较弱的 DL 方法 + 含 p 值反算方差**的产物。在严格 HKSJ + 直接方差政策下：
- body_fat 直接方差只剩 k=1，**不可合并**；
- 其效应**双向分布**，被正确降级为"优先复制假设，非疗效信号"。

这是必须如实更新的修正——**严格方法推翻了 06-13 的体脂信号**。同时它精确定位了瓶颈：**直接方差是约束**（仅 13 研究 / 39 行有 reported SD/CI）。

## 四、模型重新规划

### A. 效应量线 —— 改变目标（关键转向）
聚合 RCT 的效应量"**预测**"在当前数据 + 严格方法下已证不可行（0 越基线、0 可复制）。转向：
- **从"预测模型"改为"证据综合 + 复制优先级"**：HKSJ meta 产出诚实合并区间 + 异质性 + 预测区间；交付物是"**哪些干预-结局值得做确证试验**"（weight、body_fat 列为复制假设），而非一个预测器。
- 与审计的 `priority_replication_hypothesis` 定位一致。**不再追求让模型越过基线**。

### B. 数据采集 —— 唯一杠杆，现已精确瞄准
- **瓶颈 = 直接方差**。定向策展报告**臂级 SD/CI** 的 weight|kg 与 body_fat|kg 研究，把直接方差 k 从 4 提到 ≥10。这是让 HKSJ 区间收窄、可能达到 replication-ready 的唯一统计途径。
- **个体级 IPD**（同批人基线菌群 + 各自应答）仍是建**真个体应答模型**的唯一路径——聚合数据再严谨也只能到 meta 综合，到不了个体预测。

### C. 肥胖状态模型 —— 强化已验证资产（不受本次否定影响）
- 仍是项目唯一有内部信号的模型（分组 AUC 0.729）。
- 升级：加 MetaPhlAn 功能通路 + α/β 多样性特征、序数回归、概率校准、**争取外部数据集做真正的外部验证**（当前仅内部分组验证）。

### D. 组合 / 筛选 —— 不变，疗效门更有据
- 223 菌库、安全分流、机制设计假设继续作为**设计+安全轴**。
- 疗效门保持关闭——本次严格分析为"不发疗效排序"提供了更硬的依据。

### E. 方法学 —— 以严格综合为新标准
- HKSJ/PM + 直接方差 + 共干预排除 + 稳健性三角 + 证据层敏感性 = 常规流程，**不回退 DL**。
- 决策规则（来自 evidence_layer_sensitivity）：信号方向跨层变化、或更严过滤后区间支持消失 → **不可行动**。

## 五、待更新的交付物

## 六、一句话结论
严格化更新**没有削弱项目，反而提升了可信度**：它用正确的小样本方法证明了——**聚合 RCT 在当前数据下无可复制的疗效信号**（含此前的体脂信号），把努力方向**从"调模型"彻底锁定到"采数据"**（直接方差研究 + 个体级 IPD）。肥胖状态模型与菌株设计链不受影响，照常推进。
