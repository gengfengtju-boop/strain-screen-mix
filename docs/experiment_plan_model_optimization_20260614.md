# 预测模型优化实验计划与方案（2026-06-14）

## 0. 前提与原则

**模型现状分诊**：
- **肥胖状态模型**：内部分组 AUC 0.729 —— 唯一有信号、**模型优化能见效**的对象。本计划主战场。
- **干预效应量模型**：严格 HKSJ 下 0 可复制信号 —— **瓶颈是数据不是模型**，调模型无用；本计划只给"数据采集实验"。

**贯穿原则（防自欺）**：
1. 一切以**按研究分组 CV**或**外部验证**为准，随机 CV 仅用于量化乐观偏差。
2. **预注册成功判据**（下表），达不到就如实报负结果，不调参凑。
3. 多重比较控制：≥3 个配置对比时报 bootstrap CI，不挑最好看的。
4. 嵌套 CV：调参在内层，评估在外层，杜绝选择性泄漏。

## 第一部分：肥胖状态模型优化（E1–E6，模型可见效）

### E1. 功能 + 多样性特征增强
- **假设**：MetaPhlAn 通路（HUMAnN）+ α/β 多样性 + F/B 比，能在物种丰度之外增加信号。
- **方法**：从 curatedMetagenomicData 取 `functional_profile`（pathway 丰度）；算 Shannon/observed richness、PCoA 前若干轴、Firmicutes/Bacteroidetes 比；与物种-only 基线在**同一分组 10 折 CV**下比 AUC/R²。
- **成功判据**：分组 AUC 提升 ≥0.02 且 bootstrap CI 不重叠；或 BMI R² 增量 ≥0.03。
- **诚实预期**：温和；功能常与物种共线。

### E2. 算法基准（嵌套分组 CV）
- **假设**：当前 HGB 非最优。
- **方法**：HGB vs RandomForest vs XGBoost vs LightGBM vs ElasticNet（+ 可选 TabPFN），**嵌套分组 CV**（内层调参、外层评估）。
- **成功判据**：最优模型分组 AUC 的 CI 下界 > 当前 0.729 点估计。
- **附加价值**：ElasticNet 给可解释的稀疏生物标志物。

### E3. 批次/混杂校正（最高价值之一）
- **背景**：随机 vs 分组差距（0.73 vs 0.83）= 研究批次混杂。
- **假设**：去除批次效应后，模型**更可迁移**（分组 AUC 维持或上升，乐观偏差缩小）。
- **方法**：对物种矩阵做 MMUPHin / ComBat 批次校正，或每研究内秩标准化；重跑分组 CV；对比校正前后的「分组 AUC」与「随机−分组差距」。
- **成功判据**：分组 AUC 不降 **且** 乐观偏差（随机−分组）缩小 ≥30%。
- **意义**：这是判断"0.73 里有多少是真生物学"的关键实验。

### E4. 序数三分类 + 概率校准
- **方法**：序数回归（lean<overweight<obesity，OrderedModel）；isotonic/Platt 校正；分组 CV 下报校准曲线、Brier、校准斜率。
- **成功判据**：校准斜率 ∈ [0.9,1.1]，Brier 较未校正下降；序数模型对中间梯度（overweight）AUC>0.6。

### E5. 外部验证（决定性实验）
- **假设**：模型在 45 研究之外仍可迁移。
- **方法**：① 留出整组研究作外部集（leave-one-cohort-out 到底）；② 物色一个**不在当前 45 研究内**的独立队列（curatedMetagenomicData 仍有未纳入的肥胖相关研究），仅作测试。
- **成功判据**：外部 AUC > 0.65。
- **意义**：这是"肥胖模型是否超越内部"的硬门槛；过了才能称外部有效。

### E6. 稳健生物标志物选择
- **方法**：重复分组 CV + 稳定性选择（stability selection），找跨研究稳健预测的物种。
- **成功判据**：得到 10–20 个稳健签名，其单独分组 AUC > 0.68（精简且可部署）。
- **附加**：与 SHAP 签名、Phase 4.1 耗竭谱交叉验证一致性。

**E1–E6 执行顺序建议**：E3（批次）→ E5（外部）先做（决定模型"真实性上限"）；再 E1/E2/E6（榨增量）；E4（校准）收尾产品化。

## 第二部分：效应量线 —— 数据采集实验（E7–E8，模型无用）

### E7. 功效/样本量模拟（精确化策展目标）
- **问题**：还需多少个**直接方差**研究，weight/body_fat 的 HKSJ 区间才能复制就绪？
- **方法**：以现有 k=4 weight 研究的效应/SD 分布为基，蒙特卡洛模拟逐步加入 n 个新研究（抽样真实 SD），记录 HKSJ 95%CI 与预测区间何时稳定排除 0。
- **产出**：明确策展靶量（如"再 8 个报告 SD 的 weight RCT"）+ 对 SD 大小的敏感性。

### E8. 个体级 IPD 可行性扫描
- **问题**：哪些益生菌 RCT 公开了**每个受试者**的基线菌群 + 各自应答？
- **方法**：系统检索 SRA/ENA BioProject（益生菌干预 + 16S/shotgun + 时间点）配对补充材料的 per-subject 结局；curatedMetagenomicData 含时间点的干预子集。
- **产出**：IPD 可用研究清单 + 建个体应答模型的可行性评估。这是**唯一**能把应答从"群体 meta"推进到"个体预测"的路径。

## 成功判据汇总（预注册）

| 实验 | 成功判据 | 失败即如实报 |
|---|---|---|
| E1 功能特征 | 分组 AUC +≥0.02（CI 不重叠）| 无增量 |
| E2 算法 | 最优 CI 下界 > 0.729 | 各算法等价 |
| E3 批次校正 | 分组 AUC 不降 + 乐观偏差 −≥30% | 校正无助迁移 |
| E4 校准 | 校准斜率∈[0.9,1.1] | 概率不可靠 |
| E5 外部验证 | 外部 AUC > 0.65 | 不可迁移（关键负结果）|
| E6 稳健签名 | 精简签名分组 AUC > 0.68 | 无稳健子集 |
| E7 功效模拟 | 给出明确靶量 | — |
| E8 IPD 扫描 | ≥3 个 IPD 可用研究 | IPD 不可得 |

## 资源与依赖

- **可在本环境做**：E1（需重抓 functional_profile，R/CMD）、E2、E4、E6、E7（纯模拟）、E8（联网检索）。
- **需额外包**：MMUPHin/ComBat（E3，R/Bioconductor 或 python `combat`）、XGBoost/LightGBM（E2，pip）、statsmodels OrderedModel（E4）。
- **E5 外部验证**：需确认 curatedMetagenomicData 中未纳入的独立肥胖队列。

## 优先级建议

1. **E3 + E5**（批次校正 + 外部验证）—— 决定肥胖模型的真实性上限，最高价值。
2. **E7 + E8**（功效模拟 + IPD 扫描）—— 给效应量线明确的数据路线，低成本高方向价值。
3. **E1/E2/E6** —— 榨取肥胖模型增量。
4. **E4** —— 产品化校准，收尾。

## 诚实边界
- 肥胖模型优化**最多把内部 0.73 做扎实并验证外部可迁移**，不会让它变成个体应答模型。
- 效应量线**没有模型实验能解锁疗效**——E7/E8 是采数据的前置，不是建模。
- 全程：外部/分组验证为准、预注册判据、负结果照报。
