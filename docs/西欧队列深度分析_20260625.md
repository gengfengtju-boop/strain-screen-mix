# 西欧队列深度分析：混杂审计 · 跨国泛化 · 稳健差异菌

**日期**：2026-06-25 ｜ 西欧为分层中 AI 可分性最强者（初始 AUC 0.745，2 220 瘦 / 1 136 胖，20 项研究、11 国）。本文对该信号做**严格混杂审计**，并提取跨国稳健差异菌。

## 一、信号审计链（核心）

| 检验 | AUC | 含义 |
|---|---|---|
| 原始（肥胖组含 T2D）分组 5 折 | 0.744 | 起点 |
| 仅健康肥胖（剔除 T2D）分组 5 折 | 0.707 | 疾病混杂影响有限 |
| 仅健康肥胖 **留一研究(LOSO)** | 0.699 | **跨研究可泛化** |
| 肥胖组内 T2D vs 健康 | 0.504 | **≈随机**，疾病非信号来源 |
| **仅年龄+性别** | **0.722** | ⚠ **强于菌群**，原始比较存在人口学混杂 |
| 仅菌群（健康） | 0.695 | 菌群单独效力 |
| **年龄性别严格匹配后菌群** | **0.73** | ✅ **混杂剥离后信号仍成立** |
| 菌群 + 年龄性别 | 0.761 | 二者信息互补 |

**结论（诚实且重要）**：
1. **T2D 不是信号来源**——肥胖组内 T2D vs 健康判别 AUC 仅 0.504（≈随机），剔除 T2D 后 AUC 仅从 0.744 降至 0.707。
2. ⚠ **人口学是真实混杂**——瘦人平均 42.1 岁、女性 66%，肥胖 51.9 岁、女性 55%；**仅用年龄+性别即可达 AUC 0.722，高于菌群单独的 0.695**。任何未校正的“菌群区分胖瘦”结论都被高估。
3. ✅ **但菌群信号真实存在**——按年龄±3 岁、同性别 1:1 匹配（n=1356，两组均值 51.8 vs 51.9 岁）后，**纯菌群 AUC 仍达 0.73**，且联合模型升至 0.761，说明菌群携带独立于人口学的信息。

## 四、生物学解读
1. **胖人富集呈现明确的“口腔菌易位”特征**：*Streptococcus gordonii / sanguinis / parasanguinis / mitis* 与 *Actinomyces oris* 均为口腔常驻菌，在肥胖者粪便中稳定富集（4 国一致）。这与口腔—肠道菌群易位、低度炎症的既有机制假说吻合，且**独立于年龄性别混杂**（见审计链）。
2. **瘦人富集完全支持前期组合骨架**：*Odoribacter splanchnicus*（+0.47，全分层最强）、*Barnesiella intestinihominis*、*Eubacterium siraeum*、*Alistipes indistinctus*、*Oscillibacter* 均为丁酸/丙酸产生菌——**与数据驱动协同组合的成员一致**，说明该组合在最大、最可靠的分层中获得独立验证。
3. *Faecalibacterium prausnitzii*（+0.34，4 国 100% 一致）在西欧达到稳健阈值——此前全局分析中它仅 10/15 一致而未入选，**分层后信号显现**，提示应作为西欧人群的优先候选。

## 五、对组合设计的直接结论
- **西欧人群优先组合**：可在原骨架（*Odoribacter* + *Barnesiella* + *E. siraeum* + *B. intestinalis*）基础上**加入 *F. prausnitzii***（丁酸轴增强，西欧稳健）。
- **应抑制目标**：口腔链球菌属易位（*S. gordonii/sanguinis/parasanguinis*）可作为西欧人群的**减脂干预疗效标志物**（下降=有效）。
- **人群适配必须校正年龄性别**：任何基于菌群的胖瘦分型/评分，若不做年龄性别校正，将高估效力。

## 六、诚实边界
1. 跨国泛化仅 0.56–0.69，模型不可跨队列直接迁移；DEU 留出仅 12 例肥胖，估计不稳。
2. 差异为**关联非因果**；口腔菌易位为机制假说，需实验验证。
3. 匹配分析样本量降至 1 356，置信区间较宽；未校正饮食、用药等其他混杂（数据缺失）。
4. 本分析不改变疗效门控——组合仍以候选定标交付。
