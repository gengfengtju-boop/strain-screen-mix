# 数据驱动的协同减脂菌株组合（多维综合打分）

**日期**：2026-06-25 ｜ 从瘦人(无胰岛素抵抗)富集菌中筛选具有**机制协同**的 3–5 株组合。

## 一、预测依据与打分口径
- **预测依据**：每个成员都是**瘦人(无胰岛素抵抗)相对胖人显著富集**的物种（15 研究内求差、跨研究中位、方向 ≥11/15 一致）；并已排除促炎菌（*Bilophila*、*Desulfovibrio*）与仅 MAG/未培养物种。
- **协同 = 机制互补**：组合按覆盖的不同功能轴数计分——**丁酸**(GLP-1/饱腹/屏障)、**丙酸**(饱腹/抑脂)、**黏液/屏障**、**BSH/降胆固醇**；要求 ≥3 轴。
- **综合分** = 0.28·协同 + 0.26·减脂潜力 + 0.16·降胆固醇 + 0.14·菌株性质(可培养) + 0.10·效应 + 0.06·属多样性。

## 四、诚实边界
1. **关联非因果**：成员的减脂依据是"瘦人富集"的横断面关联，"补充能否致减重"仍需个体级数据(IPD)或前瞻 RCT 验证；疗效门保持关闭。
2. **功能为属级先验**：如 *Eubacterium siraeum* 属级标为 uncharacterized，丁酸功能可能被低估；机制轴需菌株级基因组功能注释确认。
3. **必经安全门**：候选多为新型益生菌(NGP)/严格厌氧，进入验证前须完成菌株级基因组 AMR/毒力/MGE 筛查与真实可培养性/产业化评估。
4. **降胆固醇受限**：数据驱动的瘦人富集池里 BSH 多为弱(bsh=1)，降胆固醇分普遍 0.5；强 BSH 需引入乳杆菌属，与"完全数据驱动"有取舍。
