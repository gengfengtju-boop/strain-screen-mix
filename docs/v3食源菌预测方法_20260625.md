## 一、为什么食源菌必须另立方法

前述 v2 与地区化方法均以**队列差异丰度**为核心依据，但这套依据对食源菌根本不适用，原因有两条硬约束：

**（1）多数食源菌在肠道队列中不存在。** 38 株食源菌的队列证据状况：

| 队列证据状况 | 株数 |
|---|---|
| 队列无数据（不可得） | 15 |
| 队列受检但不显著 | 15 |
| 队列反证：肥胖富集 | 5 |
| 队列支持：瘦人富集 | 3 |

**仅 3 株有支持证据，15 株在队列中根本不出现**（流行率<10%）——乳杆菌类是过路菌而非肠道常驻菌，这不是数据缺陷，而是生物学事实。

**（2）食源菌在瘦人判别轴上完全同质。** 全部 38 株的丁酸=0、丙酸=0、黏液=0，均为乳酸-乙酸产生菌。**因此在西欧分析中最有效的判别指标（丙酸潜能、多样性关联）无法对它们排序。**

## 二、v3 方法设计：迁移瘦人生态判据，结合自下而上

**主评分完全不使用队列丰度**，改由六个可对食源菌计算的维度构成：

| 维度 | 权重 | 判据来源与理由 |
|---|---|---|
| **交叉喂养供能** | 0.22 | 瘦人菌群呈“协作型”生态（与高多样性共存）。食源菌产乳酸/乙酸，可作为常驻丁酸/丙酸产生菌的底物，**间接支持协作型生态**。⚠️ 这是从瘦人分析迁移来的**机制假设**，本文未验证 |
| **BSH 胆汁酸调节** | 0.15 | BSH 已被证明**不能**预测常驻菌的瘦人富集（AUC 0.517），但对**外源补充乳杆菌**是有文献支持的降胆固醇机制。这是 BSH 唯一合理的适用场景 |
| **安全等级** | 0.22 | 自下而上目录：EFSA QPS/GRAS 低门槛 vs 需菌株级审查 |
| **临床证据** | 0.15 | 自下而上目录：是否已有人体试验先例 |
| **工业可行性** | 0.14 | 可培养性 + 稳定性（芽孢/酵母耐受性高）。**注意：芽孢形成在工业上是优点，在生态上是肥胖倾向特征，本方法将二者分开计分** |
| **肥胖特征惩罚** | −0.12 | 口腔来源属（西欧已验证肥胖富集）+ 糖降解主导型（肥胖通路特征）|

**队列证据的处理方式**：按设计要求**不进入评分**，但作为**独立旗标**单独报告——因为忽略“某菌在队列中显著肥胖富集”这一事实并不稳妥。

## 四、推荐组合

### 方案 A｜全局最优（综合 0.9035，2 株）

**副干酪乳酪杆菌 + 植物乳植杆菌**

两株均具强 BSH + 强交叉喂养 + 临床证据 + QPS 安全。**但两者在队列中均无数据**（乳杆菌属不出现于肠道队列）。

### 方案 B｜含队列支持成员（综合 0.8754，3 株）⭐ **推荐**

**副干酪乳酪杆菌 + 植物乳植杆菌 + 动物双歧杆菌**

在方案 A 基础上加入**动物双歧杆菌**——它是仅 3 株拥有队列支持证据者之一（西欧显著瘦人富集，FC=0.62，FDR=0.004）。综合分仅比方案 A 低 0.0281，但**获得了独立的队列证据支撑**，且三株均有临床先例。

**为什么推荐 B 而非 A**：方案 A 的评分优势来自工业可行性（乳杆菌 0.90 vs 双歧杆菌 0.60），属工程属性；方案 B 牺牲少量工程便利，换取一项真实的人群证据，在“预测减脂”这一目标上更稳妥。

## 六、与前述方法的关系

| | v2 / 地区化方法 | **v3 食源菌方法** |
|---|---|---|
| 适用对象 | 肠道常驻菌（NGP、共生菌）| **食源益生菌**（乳杆菌、双歧杆菌等）|
| 核心依据 | 队列差异丰度 + 多样性关联 | **菌株性质**（交叉喂养、BSH、安全、临床、工业）|
| BSH 地位 | 已移除（预测无效）| **保留**（外源补充范式下有文献支持）|
| 队列数据 | 评分核心 | **仅作旗标，不计分** |
| 落地难度 | 高（多为 NGP，需基因组安全门 + 严格厌氧发酵）| **低**（QPS/GRAS、工艺成熟）|
| 证据强度 | 有人群关联证据 | 多数无人群证据，依赖机制假设 |

**两套方法互补而非替代**：v2/地区化方法给出“生物学上最该恢复的菌”，v3 给出“当下最可落地的菌”。理想产品路线是先用 v3 组合快速落地，同时推进 v2/地区化组合的安全与临床验证。

## 七、局限（重要）

1. ⚠️ **交叉喂养与工业可行性两轴是机制/工程先验，本文未针对减脂结局验证**——这是 v3 相对 v2 的根本弱点：v2 的主要权重有队列验证支撑，v3 没有。
2. ⚠️ **属级注释导致乳杆菌属内完全同分**：7 株乳杆菌 v3 分均为 0.761，方法无法在属内区分。要做菌株级排序，必须补充**菌株级基因组与体外表型数据**（实际 BSH 活性、产酸量、耐胆盐/耐酸性、黏附能力）。
3. **BSH 的降胆固醇效应本身在本项目中未能检验**（可关联菌种的血脂结局仅 6 行），故 0.15 的权重来自文献而非本文数据。
4. **交叉喂养假设需体外验证**：应通过共培养实验证明该食源菌确能提升常驻丁酸/丙酸菌的产酸量。
5. 组合仍为**候选定标**，非疗效预测；须经体外 → 动物 → 人体 RCT 验证。
