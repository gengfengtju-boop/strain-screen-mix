# 菌体组合稳健优化模型（2026-06-10）

## 模型定位

本模型利用 134 条结构化终点，对 7 个已有临床证据的配方块、11 株候选菌进行 3–5 株组合优化。模型输出是体外/动物/前瞻试验的验证优先级，不是个体减重响应概率，也不能替代安全性评价。

原研究级响应分类器在 37 项研究上的 AUC 为 0.484，未超过基线，因此不再把该分类器概率传播到菌株组合。新模型直接使用已经确认的阳性、有限和阴性结局，并显式保留不确定性。

## 最新算法文献依据

- Hollmann 等在 Nature 2025 发表 TabPFN，表明预训练表格基础模型特别适合样本量小于 10,000 的异质表格数据，并可直接输出后验预测分布：<https://doi.org/10.1038/s41586-024-08328-6>。
- Chen 等在 Nature Methods 2024 总结计算生物学可解释机器学习的常见陷阱，强调防止标签泄漏、区分预测与解释、采用匹配生物问题的验证方式。
- 组合治疗和生物设计领域近期工作普遍采用图表示、贝叶斯优化和主动学习，以处理组合空间远大于可实验样本数的问题。当前数据没有菌株基因组嵌入、共培养矩阵或已测组合标签，因此直接训练 GNN/Transformer 会产生无法验证的参数。

2026-06-11 已安装 TabPFN 8.0.8 和 PyTorch 2.12.0 CPU 版，并成功下载 29 MB 的官方 TabPFN-v2 分类器 checkpoint。仅使用 4 个基础描述字段时，134 条终点、37 项研究的五折分组验证为 AUC=0.381、AP=0.329。加入干预类别、菌属家族、人群、盲法、随机/安慰剂设计、样本量、持续时间和 CFU 剂量后，114/134 条终点获得增强特征。单次 4-estimator 结果为 AUC=0.509、AP=0.436，但 5 个随机种子的重复五折分组验证显示 AUC=0.463+/-0.078、AP=0.402+/-0.046、Balanced Accuracy=0.491+/-0.038，单次提升不稳定。TabPFN 未达到稳健融合门槛，因此没有进入组合排名，当前最优组合保持不变。

项目新增 `proslim-ai benchmark-tabpfn` 命令，只接受明确的本地官方 checkpoint，不会在正式流程中隐式联网。可通过重复 `--review` 参数加入人工复核特征，并通过 `--cv-repeats` 执行多随机种子重复验证；所有类别编码和数值缺失值填补均在每个训练折内拟合。仅当平均 AUC 不低于 0.55、平均 AUC 减一个标准差不低于 0.50，且平均 AP 超过阳性率基线时，输出才标记为可参与组合融合。真实指标见 `results/prediction_results/tabpfn_benchmark_metrics*_20260611.json`。当前结果说明仍需补充菌株基因组嵌入、准确剂量、基线人群和实测组合交互特征。

2026-06-11 进一步将上述 13 个泄漏安全特征接入正式响应模型，并在内层加入 3 档逻辑回归正则化。单次嵌套分组验证可达到 AUC=0.562、AP=0.456，但 5 个随机种子的重复嵌套验证为 AUC=0.519+/-0.041、AP=0.444+/-0.040，仍未通过稳定门槛。因此优化模型及预测表已保存用于后续数据增量复跑，但当前不向菌株组合排名传播概率。

## 算法

1. 按 adiposity、metabolic、microbiome 分别赋予 1.00、0.70、0.35 的终点权重。
2. 阳性、有限、阴性结局分别记为 1、0.5、0，并对 PP、亚组、组内结果、提前终止等证据降权。
3. 每个配方使用 Beta 后验生成证据分布，避免把单项小样本研究当作确定真值。
4. 枚举全部 940 个 3–5 株且至少跨两个菌属的组合。
5. 综合临床证据、功能模块覆盖、原配方完整性、独立证据来源和菌属多样性，并扣除配方拆分与复杂度惩罚。
6. 进行 5,000 次 Monte Carlo 模拟，同时扰动证据后验和评分权重，输出均值、P10/P90、Top-10 概率及排名分布。
7. 在疗效均值、信息增益和组合复杂度上构建 Pareto 前沿，避免只追逐单一总分。
8. 使用上置信界和菌株集合 Jaccard 多样性，生成 8 个主动学习首批实验，平衡利用与探索。

## 当前最优候选

### 第一优先级

`L. fermentum K7 + K8 + K11 + B. lactis IDCC 4301 + B. animalis subsp. lactis B420`

- 稳健综合分：7.350，P10–P90 为 6.624–8.047。
- Top-10 入选概率：0.617。
- 完整保留 3 个已测试配方块，功能覆盖、配方完整性和证据独立性均为 10 分。
- B420 的人体证据依赖 polydextrose/Litesse Ultra 背景，实验设计中应保留该条件并设置无纤维对照。

### 第二优先级

`L. fermentum K7 + K8 + K11 + B. breve BBr60`

- 稳健综合分：7.305，P10–P90 为 6.535–8.058。
- Top-10 入选概率：0.547。
- 仅 4 株，复杂度和生产验证成本较低，适合作为精简对照方案。

### 第三优先级

`L. fermentum K7 + K8 + K11 + B420 + BBr60`

- 稳健综合分：7.267，P10–P90 为 6.542–7.967。
- Top-10 入选概率：0.537。
- 功能覆盖和独立证据较强，但同样需要验证 B420 的纤维依赖性。

## 稳定性与限制

- 随机种子 17、29、43 的 Top-1 完全一致，Top-10 两两重合 10/10。
- 第一名 Top-10 概率仅为 0.617，尚不存在压倒性最优组合，应并行验证前 3 名。
- 所有候选目前均为 `pending_genome_safety_gate`；完成菌株分辨率的 AMR、毒力、可移动遗传元件和污染检查前，不得进入人体应用。
- 当前每个配方主要由单项研究支撑，无法学习真实菌株间交互效应；协同得分仍是机制和配方完整性约束下的假说评分。

## 主动学习首批实验

首批 8 个组合标记在结果表 `active_learning_batch` 字段中。它们包括当前第一名、K7/K8/K11 与 BBr60/B420/BB536+MCC1274 的替代组合，以及不含 K7/K8/K11 的探索性组合。该批次的目标是最大化下一轮实验对模型的更新价值，而不是把 8 个组合都视为同等临床候选。

## 建议实验顺序

1. 对 11 株菌完成全基因组安全门控、身份确认、耐药和毒力筛查。
2. 对前三组合进行共培养兼容性、存活率、酸胆盐耐受和代谢互补测试。
3. 设置 K7/K8/K11 原配方、各新增单菌、完整组合和纤维背景对照，避免无法归因。
4. 通过体外结果淘汰拮抗组合后，再进入肥胖动物模型；预先定义体重、脂肪量、腰围替代指标、糖脂代谢和菌群终点。
