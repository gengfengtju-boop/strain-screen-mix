# AI 算法修复记录

更新日期：2026-06-10

## 已完成修复

1. **响应模型标签泄漏**：`direction`、组间/组内 P 值、效应差及证据修饰字段既参与标签生成又参与特征训练，现已全部从特征中排除。
2. **验证数据穿越**：模型选择与性能评估曾共用同一分组交叉验证结果，现改为按 `evidence_id` 隔离的嵌套分组交叉验证。
3. **模型层级误述**：原“响应人群模型”实际为研究终点证据分类器，现已在代码、CLI、字段和结果表中统一更名，并明确不是个体 responder 模型。
4. **无效模型继续传播**：新增信息性门槛。AUC、AP 未优于基线时，模型状态标记为 `non_informative_do_not_apply_to_combinations`，组合推荐中的模型概率保持为空。
5. **效应值解析错误**：原解析器可能把中位数和 IQR 下限误当两组效应，现按 `vs` 分组提取，并输出解析方法与警告字段。
6. **重复终点膨胀评分**：同一研究同一 outcome domain 的多行终点先取均值，再进行跨 domain 汇总，避免报告终点更多的研究获得不合理加分。
7. **组合推荐安全门失效**：安全状态为 `pending` 时仅输出假说优先级，不再输出验证优先级；`fail` 菌株从组合中排除。
8. **启发式分数伪装成概率**：候选预测和组合排序均增加分数类型说明；未通过验证的模型不再产生 `predicted_response_score`。
9. **OMS/BMI 只有配置无实现**：新增样本级 Logistic Regression OMS 基线和 ElasticNet BMI 基线，包含最小样本、研究数、类别数门槛及按研究分组验证。
10. **测试运行目录权限问题**：移除固定 `--basetemp`，新增算法回归测试，避免 Windows ACL 导致 pytest 长时间阻塞。

## 严格验证结果

- 基础集：46 个终点行、12 个研究，AUC 0.391，AP 0.323，Brier 0.277。
- 增强集：66 个终点行、17 个研究，AUC 0.319，AP 0.286，Brier 0.273，Balanced Accuracy 0.438，F1 0.063。
- 结论：当前描述性字段不足以形成有效证据分类器，模型未通过门槛，不能用于临床响应判断或菌株组合重排。

## 尚需真实数据解决的问题

- OMS 与 BMI 模型仍缺样本级菌群丰度矩阵、临床协变量和独立外部队列。
- 个体响应预测需要干预前基线菌群、个体结局变化、依从性和随机分组数据，现有研究汇总终点不能替代。
- 菌株组合进入验证前必须补齐菌株级基因组安全、耐药、毒力和可制造性结果。
