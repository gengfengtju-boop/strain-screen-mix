# 协同减脂候选菌的基因组安全门分流（AMR / 毒力 / MGE）

**日期**：2026-06-25

## 诚实范围（必读）
本环境**无法运行真版基因组筛查**（AMRFinderPlus / abricate-CARD-VFDB / ResFinder 需基因组 FASTA + 生信工具链）。本分流给出：
1. **分类学/QPS 知识先验**风险类别（复用项目既有 `safety_triage_step2.py` 逻辑）；
2. **NCBI 基因组可得性**（决定真版筛查是否可后续跑）；
3. **属级 MGE / 可移动 AMR 知识旗标**。
它**决定先筛谁 + 标注已知风险**，**不替代**菌株级真版 AMR/毒力/MGE 筛查。

## 关键安全旗标（影响首选组合）
- **Akkermansia muciniphila / Odoribacter splanchnicus**：LBP **人体试验前例**，风险最低，MGE 低/未知——优先筛查批次。
- ⚠️ **拟杆菌属（含首选组合的降胆固醇株 *Bacteroides intestinalis*）：MGE 高·必查**。拟杆菌门是可移动 **tetQ / ermF / cfxA** 与接合转座子(CTn)的已知储库——这是首选组合最需重点筛查的移动 AMR 风险点。
- **Butyrivibrio / Barnesiella / Alistipes / Intestinimonas**：新型共生，MGE 未知，须做全套基因组筛查。

## 对首选组合的含义
首选组合（肠拟杆菌 + 嗜黏蛋白阿克曼氏菌 + 人肠巴恩斯氏菌 + 丛毛丁酸弧菌）：Akkermansia 降险、其余为新型共生需筛；**降胆固醇来自拟杆菌(MGE 高)**——若移动 AMR 筛查不过，应以其他 BSH 来源（如 *Lactobacillus rogosae*）替换，在降险与降胆固醇间权衡。

## 下一步（真版筛查，需生信环境）
1. 按表中 NCBI 登记号下载各候选代表基因组（每株 ~2–6 MB，合计 <100 MB）。
2. 跑 **AMRFinderPlus**(AMR)、**abricate + VFDB**(毒力)、**MobileElementFinder/PlasmidFinder**(MGE/可移动 AMR)；拟杆菌重点查 tetQ/ermF/cfxA + 接合转座子。
3. 仅无可移动 AMR、无毒力因子、无高风险 MGE 的菌株进入体外/动物验证。
