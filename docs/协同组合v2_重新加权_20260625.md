## 一、为什么要重新加权

v1 的权重来自机制假设，v2 的每一项调整都由**实测验证结果**驱动：

| 评分项 | v1 | v2 | 调整依据 |
|---|---|---|---|
| **与多样性关联** | — | **0.30** | AUC **0.920**，且是**唯一能跨属泛化**的特征（留一属 0.878）|
| **实测胖瘦效应** | 0.10 | **0.24** | 直接来自西欧严格分析的 meta 合并效应 g |
| 机制互补 | 0.28 | 0.16 | 仍是组合设计原则，但不再主导 |
| 丙酸潜能 | (含于减脂项) | 0.12 | AUC 0.647（样本内 10/10），但跨属仅 0.321 |
| 菌株性质(可培养) | 0.14 | 0.10 | 基本不变 |
| 属多样性 | 0.06 | 0.08 | 组合层面 |
| **BSH 降胆固醇** | **0.16** | **0.00 移除** | AUC **0.517**（P=0.85）；跨属 **0.027**（系统性反向）；加入后最佳模型 0.878→0.798 |
| 丁酸(作为正向项) | 隐含 | **不计** | AUC 0.540 且方向相反（78% < 基线 84%）|
| **惩罚项** | — | 芽孢形成 −0.05 / 口腔来源 −0.10 | 二者均为肥胖富集倾向 |

**候选池也升级**：v1 用全局未校正分析的 53 株；**v2 改用西欧健康人群（排除 T2D、年龄性别匹配、FDR+meta 双重验证）的稳健瘦人富集菌**，并剔除促炎菌（*Bilophila*、*Desulfovibrio* 科）、未培养 MAG 与古菌，最终 **16 株**。

## 四、v1 → v2 首选组合的变化

| | 组合成员 |
|---|---|
| **v1 首选** | 嗜黏蛋白阿克曼氏菌, 肠拟杆菌, 人肠巴恩斯氏菌, 丛毛丁酸弧菌 |
| **v2 首选** | 腐败另枝菌, 人肠巴恩斯氏菌, 内脏臭杆菌 |
| 保留 | 人肠巴恩斯氏菌 |
| 剔除 | 嗜黏蛋白阿克曼氏菌, 肠拟杆菌, 丛毛丁酸弧菌 |
| 新增 | 腐败另枝菌, 内脏臭杆菌 |

**逐项原因**：
1. ⚠ **嗜黏蛋白阿克曼氏菌被剔除**——原因是**未通过稳健性三重判定**：在西欧严格分析中它确实显著（FDR=0.013）且方向为瘦人富集（g=+0.17），但**随机效应 meta 的 95%CI 未排除 0**（跨研究异质性较大），故未进入 v2 候选池。**这是一个边界案例**：该菌文献证据充分且已商业化，若产品策略需要，可将其作为**敏感性方案**单独纳入，但须标注其跨研究一致性不足。
2. **肠拟杆菌与丛毛丁酸弧菌仍在候选池内**（均为稳健菌），只是多样性关联较低（ρ +0.16 / +0.10），在新权重下排名下降，出现在 v2 #3/#7 等组合中。
3. **新增内脏臭杆菌与腐败另枝菌**：二者多样性关联位列前三（ρ +0.35 / +0.33），在 v1 中因权重未包含该维度而被低估。
4. **人肠巴恩斯氏菌是唯一在两版中都居首的菌**（ρ +0.36 最高，g +0.18），可视为最稳健的核心成员。

## 五、诚实边界

1. **权重仍为专家设定**，非从结局数据拟合而来；v2 的改进在于**每一项权重都有验证依据**，而非机制猜想。
2. **多样性关联为横断面关联**，无法区分「菌促进多样性」还是「多样环境利于该菌」，其高 AUC 不等于因果效力。
3. **候选池收窄至 16 株**（严格三重判定的代价），可能遗漏真实有效菌（如阿克曼氏菌）；建议同时保留一个**放宽版**（仅要求 FDR<0.05）作敏感性分析。
4. **组合仍是候选定标，非疗效预测**；疗效门保持关闭，须经基因组安全筛查 → 体外 → 动物 → RCT 验证。
5. 结论基于西欧人群；东亚等人群需用对应分层重新加权。
