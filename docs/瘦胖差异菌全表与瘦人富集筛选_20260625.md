## 二、瘦人富集菌的筛选：功能相关 / 互补 / 可培养性

对 53 个瘦人富集菌按三维度打分（脚本 `screen_lean_enriched_candidates.py`）：

- **功能相关**：属级 guild 的丁酸/丙酸/黏液/BSH 潜能与已知减脂机制（屏障、GLP-1、饱腹、脂代谢），扣减不良机制。
- **机制互补**：奖励覆盖**丁酸/丙酸/黏液**——即现有乳杆菌/双歧组合（仅 BSH+乳酸）的盲区。
- **可培养性**：命名菌株可培养性先验（易培养/可培养厌氧/苛养/未培养 MAG）。
- 综合分 = 0.32·效应 + 0.28·互补 + 0.20·功能 + 0.20·可培养。

## 三、诚实边界

1. **功能为属级先验**：如 *Eubacterium siraeum* 在属级被标为 uncharacterized（Eubacterium 属异质），
   其丁酸/功能可能被低估；菌株级需基因组功能注释确认。
2. **多为新型益生菌(NGP)/严格厌氧**：上述候选须先过**基因组安全门（AMR/毒力/MGE）** 与
   **真实可培养性/产业化**评估，方可进入验证——衔接既有 NGP 计划。
3. **关联≠因果**：差异丰度只说明"瘦人里更多"，"补充该菌能否致减重"仍需个体级数据(IPD)或前瞻 RCT。
   本筛选产出的是**数据驱动的候选定标**，不是疗效结论；疗效门保持关闭。
